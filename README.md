# TodoApp на React и Vite (Todo List Application)

Минималистичное и функциональное приложение для управления задачами (Todo List), разработанное с использованием React и Vite. Приложение имеет головой ввод, поддерживает темную/светлую тему, использует локальное хранилище и интегрировано с mock API для имитации серверного взаимодействия.

[**&#128279; Посмотреть живое демо на Vercel**](https://todo-app-phi-puce-98.vercel.app/)

---

## :rocket: Используемые технологии

Проект реализован с использованием современного стека технологий:

- **[React](https://reactjs.org/)**: Основная библиотека для построения пользовательского интерфейса.
- **[Vite](https://vitejs.dev/)**: Быстрый сборщик проекта и сервер разработки.
- **[Tailwind CSS](https://tailwindcss.com/)**: Утилитарный CSS-фреймворк для быстрого и адаптивного дизайна.
- **[TypeScript](https://www.typescriptlang.org/) (Опционально, если используете)**: Для статической типизации и повышения надежности кода.
- **[MockAPI.io](https://mockapi.io/)**: Для эмуляции REST API и работы с задачами на "сервере".

---

## :gear: Функционал приложения

- **Управление задачами (CRUD):** Добавление, просмотр, обновление и удаление задач.
- **Состояние выполнения:** Отметка задач как выполненных.
- **Локальное хранилище:** Сохранение задач в `localStorage` для постоянства данных.
- **REST API интеграция:** Взаимодействие с внешним API для имитации бэкенда.
- **Переключение тем:** Поддержка светлой и темной тем оформления.
- **Модальные окна:** Подтверждение удаления задач.
